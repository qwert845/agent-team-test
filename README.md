# agent-team-test

여러 사람이 각자 자기 AI로 한 게임을 만들 때의 작업 규칙을 시험하는 저장소. 게임은 장난감이다(과녁을 눌러 점수를 얻는 30초 게임).

- 작업 규칙: [AGENTS.md](AGENTS.md)
- 영역 사이의 약속: [contracts/](contracts/)

## 실행하기

저장소 폴더에서 터미널을 열고 다음 명령으로 작은 웹 서버를 띄운다.

```
python -m http.server 8000
```

Windows에서 `python` 명령이 안 되면 `py -m http.server 8000`을 쓴다. Node만 있다면 `npx serve .`로 서버를 띄울 수 있다.

Python 서버를 띄웠다면 브라우저에서 <http://localhost:8000/>을 연다. `npx serve .`를 썼다면 터미널에 표시된 주소를 연다. 서버를 끌 때는 터미널에서 `Ctrl+C`를 누른다.

테스트는 저장소 폴더에서 `npm test`로 돌린다(Windows PowerShell에서는 `npm.cmd test`).

## 게임 기능

- 과녁을 누르면 점수가 올라간다.
- 남은 시간이 `분:초`로 표시된다.
- 남은 시간 막대가 시간이 지날수록 줄어든다.
- 남은 시간이 5초 이하이면 시간 표시와 막대가 빨간색으로 바뀐다.
- 빠르게 연속으로 맞히면 연속 횟수가 표시되고 점수 보너스를 받는다.
- 끝난 판들 중 최고 점수가 표시된다.
- 과녁을 맞히면 잠깐 밝아진다.
- 시간이 끝나면 `다시 하기` 버튼으로 새 판을 시작할 수 있다.
